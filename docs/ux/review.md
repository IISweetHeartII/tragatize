## 3. 데모 모드 상세

**목표: 클릭 1번 → 0초 대기 → 숏폼 3개 + 대본 보기.** API 호출 없음(키·레이트리밋·Scribe 지연과 무관).

| 단계 | 할 일 | 시간 |
|---|---|---|
| 1 | 팀원이 폰으로 **1~2분 세로 라이브 샘플** 촬영(약과 소개 등, 말 많이). 720p·10MB 이하 | 15분 |
| 2 | 지금 배포된 스튜디오에 그 영상을 올려 실제 결과를 받음 → 개발자도구 Network 에서 `/api/highlights` 응답 JSON 복사 | 5분 |
| 3 | 영상은 그때 올라간 **Blob 공개 URL 을 그대로 재사용**(레포에 바이너리 안 넣음). JSON 은 `src/lib/demo.ts` 에 상수로 | 5분 |
| 4 | 같은 상품으로 대본도 한 번 생성해 `DEMO_SCRIPT` 로 저장 | 5분 |
| 5 | UI 연결 | 15분 |

```ts
// src/lib/demo.ts — 실제 실행 결과를 붙여 넣은 상수(조작 아님: «샘플 결과» 라고 화면에 표시)
export const DEMO_VIDEO_URL = "https://<id>.public.blob.vercel-storage.com/live/sample-....mp4";
export const DEMO_SCRIPT: LiveScript = { /* /api/script 응답 */ };
export const DEMO_HIGHLIGHTS: Highlight[] = [ /* /api/highlights 응답 */ ];
```

UI (`studio-client.tsx`):
- 맨 위 배너: `[▶ 샘플 라이브로 바로 보기]` + 작은 글씨 «약과 가게 사장님이 찍은 2분 라이브 예시예요».
- 누르면 `setProduct(...)·setScript(DEMO_SCRIPT)·setVideoUrl(DEMO_VIDEO_URL)·setHighlights(DEMO_HIGHLIGHTS)·setStage("done")` 후 3단계로 `scrollIntoView`.
- `?demo=1` 이면 마운트 시 자동 실행(랜딩 CTA 용). `useSearchParams` 는 Suspense 경계 필요 → 간단히 `useEffect` 안에서 `location.search` 확인.
- 숏폼 섹션 제목 옆 배지 «샘플 결과 · 실제 AI 실행본». 아래에 «내 영상으로 다시 해보기» 링크(=Step 2 로 스크롤).
- 타입 `LiveScript`·`Highlight` 는 `demo.ts` 에서 import 하도록 옮기거나 export — 최소 변경은 studio-client 에서 `export type`.

## 5. 단계 표시 UI

**상단 스테퍼(sticky, 헤더 아래)** — 지금 어디인지, 다음에 뭘 누를지.

```
 ① 대본 ── ② 촬영·업로드 ── ③ AI 숏폼 ── ④ SNS 올리기
  ●완료       ◉진행 중         ○           ○(준비 중)
```

| 상태 | 판정 (기존 state 로 계산, 새 state 불필요) |
|---|---|
| ① 완료 | `script !== null` |
| ② 진행 | `stage === "uploading" \| "analyzing"` |
| ③ 완료 | `highlights.length > 0` |
| ④ | 항상 «준비 중» 회색 |

- 모바일: 번호 원 4개 + 현재 단계 라벨만(가로 스크롤 금지). 각 원 탭 → 해당 섹션 스크롤, 44px.

**분석 중 하위 단계** — API 는 한 번 호출이라 실제 진행률이 없다. 경과 시간 기반으로 정직하게:

| 경과 | 표시 |
|---|---|
| 업로드 | `올리는 중… {progress}%` (실제 값, 기존 그대로) + 막대 |
| 0~20초 | ✓ 업로드 · ◉ 말 받아쓰는 중(ElevenLabs) · ○ 사고 싶은 순간 고르는 중 |
| 20초~ | ✓ 업로드 · ✓ 받아쓰기 · ◉ 사고 싶은 순간 고르는 중(Claude) |
| 공통 | 경과 타이머 `0:42 · 보통 1~3분` + «기다리는 동안 [샘플 결과 보기]» 링크 |

- 구현: `analyzing` 진입 시각을 `useRef` 에 두고 1초 `setInterval` 로 경과초 갱신. 20초는 휴리스틱 — «예상» 임을 문구로 드러냄(가짜 퍼센트 막대는 쓰지 않는다).
