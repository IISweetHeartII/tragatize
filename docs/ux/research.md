# 심사위원이 60초 안에 이해하는 /studio UX

조사일: 2026-10-24 · 기준: `docs/product.md` · 남은 개발 1.5시간 / 팀 4명.

## 결론

- 첫 문장: **“라이브 한 번이면 숏폼 홍보까지 끝난다.”** 보조: “상품 대본부터 홍보 문구까지, 사장님 혼자서.”
- 첫 행동: **[샘플로 60초 체험]** / 보조 **[내 영상 업로드]**. 파일·계정이 없어도 결과를 먼저 경험한다.
- 오늘의 완료 지점: **대본 → 업로드·전사 → 하이라이트 후보 3개 → 캡션 복사**. 인스타 자동 게시를 완료로 표현하지 않는다.
- 아래는 공식 공개 페이지·가이드의 텍스트와 화면 설명을 조사한 결과다. 가입·파일 생성·게시 실행과 실제 화면 배치의 시각 검증은 하지 않았다.
- ‘미확인’은 기능이 없다는 뜻이 아니다. 특히 앱 내부 빈 상태는 공개 데모·온보딩 안내와 구분했다.

## /studio 반드시 할 것 7개

| # | 바로 적용할 항목 | 완료 확인 기준 |
|---|---|---|
| 1 | 상단 한 문장 + ‘대본 → 촬영/업로드 → 하이라이트 → 홍보 문구’ 단계 표시 | 첫 화면만 보고 대상·입력·출력을 말할 수 있음; 현재 단계 강조 |
| 2 | [샘플로 60초 체험]을 주 CTA, [내 영상 업로드]를 보조 CTA로 | 가입·파일·카메라 권한 없이 샘플을 열고 결과까지 갈 수 있음 |
| 3 | 실제 샘플 상품 1개를 기본값으로; 이름·가격·특징만 확인하면 대본 생성 | 대본에 구간·대사·촬영 지시가 보임; 샘플임을 표시하고 상품 수치가 일관됨 |
| 4 | 직접 촬영 대신 업로드도 가능한 경로 + 파일 형식/실제 용량 제한 안내 | 촬영 권한 거절·파일 없음에도 샘플 경로 유지; 지원 안 되는 URL 입력칸은 만들지 않음 |
| 5 | 진행 단계·실패 이유·재시도 + ‘샘플 결과 보기’ | 전사/분석 상태가 보임; 오류 때 입력 보존. 사전 생성 샘플은 실시간 생성과 명확히 구분 |
| 6 | 결과 3개에 썸네일/원본 구간·길이·후킹 문구·선정 이유·한/영 캡션/해시태그 | 후보를 선택하고 원본 구간을 확인할 수 있음. 잘린 파일이 없으면 ‘하이라이트 후보’로 표기 |
| 7 | 후보별 [캡션 복사]와 복사 성공 피드백; 게시 기능 상태 명시 | 복사한 내용이 실제 클립과 일치. 인스타 미연결이면 ‘자동 업로드 준비 중’, 게시 완료 배지 금지 |

숫자 점수는 우선순위 밖이다. 이미 근거 있는 평가가 구현됐다면 ‘AI 추천도’와 이유를 함께 보여주고, 조회수·매출 예측으로 표현하지 않는다.
자막 텍스트와 영상에 삽입된 자막을 구분한다. 세로 렌더링·자막 합성 미구현이면 미리보기를 완성 숏폼 파일로 부르지 않는다.

## 하지 말 것 5개

1. **가입·SNS OAuth·카메라 권한을 첫 화면에서 요구하기.** 샘플 경험 뒤에 필요한 실제 작업에만 연결한다.
2. **긴 영상 업로드·AI 처리 완료를 기다려야만 가치를 보게 하기.** 샘플 즉시 결과와 직접 생성 경로를 모두 둔다.
3. **빈 프로젝트 목록·설명 없는 업로드 박스만 보여주기.** 무엇을 넣고 무엇을 받는지 샘플로 설명한다.
4. **검증 안 된 AI 진행자·외모 보정·해외 알고리즘 최적화·예약 게시를 작동 기능처럼 배치하기.** 오늘 범위를 기준으로 상태를 표시한다.
5. **바이럴 점수·복잡한 편집기·다채널 캘린더부터 만들기.** ‘후보 선택 → 원본 확인 → 캡션 복사’ 한 장면을 먼저 완주한다.

## 심사위원 60초 동선 — 목표이며 실측 전

| 시간 | 심사위원 행동 | 화면이 증명해야 하는 것 |
|---|---|---|
| 0–5초 | `/studio` 열기 | ‘소상공인 라이브 → 홍보 자동화’ 한 문장, 로그인 없음 |
| 5–10초 | [샘플로 60초 체험] | 샘플 상품·짧은 원본 영상·완료 시 받을 후보 3개 예고 |
| 10–20초 | 상품 확인 → 대본 보기 | 구간·대사·화면 지시; 촬영할 내용을 바로 이해 |
| 20–30초 | [이 샘플 영상으로 결과 보기] | 미리 생성한 샘플 결과임을 표시; 원본과 연결된 하이라이트 3개 |
| 30–45초 | 후보 하나 선택·구간 재생 | 어느 발화를 왜 골랐는지, 어떤 후킹 문구를 붙이는지 확인 |
| 45–55초 | 한/영 캡션 확인 → [캡션 복사] | 실제 복사 성공 피드백; 문구·해시태그를 바로 가져갈 수 있음 |
| 55–60초 | [내 영상으로 만들기] 확인 | 샘플 체험 다음에 실제 업로드·전사·분석을 시도할 경로가 있음 |

- 직접 업로드·생성 시간은 별도다. 샘플의 60초 목표를 실시간 AI 처리 보장으로 말하지 않는다.
- 심사 전 새 비공개 창·모바일 폭에서 이 동선을 시간 재며 완주한다. 생성 API 실패 시에도 샘플·원본 재생·복사가 작동하는지 확인한다.
- 샘플 결과만 구현됐다면 ‘샘플 데모’로 설명한다. 실제 업로드·전사·후보 생성 성공을 별도로 확인해야 실제 처리 완주를 주장할 수 있다.
