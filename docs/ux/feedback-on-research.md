# research.md 교차 피드백 — review.md 관점 (2026-10-24)

읽은 것: `docs/ux/research.md`·`review.md`·`product.md` + 작업 트리(미커밋 변경 포함) `src/lib/demo.ts`·`studio-client.tsx`·`api/highlights/route.ts`.

## 1. 합의 (둘 다 맞고, 이미 반영 중)

- 주 CTA = 샘플 즉시 결과, 가입·카메라·OAuth 를 첫 화면에서 요구하지 않음. → 랜딩 `/studio?demo=1` CTA·헤더 «스튜디오» 하나로 정리됨(작업 트리).
- 인스타 자동 게시를 완료로 표기 금지, 점수·캘린더·편집기 보류. 이견 없음.
- 후보 3개 + 원본 구간 + 선정 이유(`why`) + 캡션 복사. 코드에 이미 있다.

## 2. 충돌·반박

- **리서치의 가장 큰 공백: 크리티컬 패스를 안 짚었다.** 지금 `demo.ts` 는 전부 빈 값이고 `HAS_DEMO=false` 면 데모 버튼이 숨겨진다. 샘플 영상 촬영·실행 결과 붙여넣기가 안 되면 리서치 7개 항목 중 1·2·5·6 이 전부 무너진다. 경쟁사 표 11줄보다 이 한 줄이 중요하다.
- **«60초 동선 7단계»는 우리 데모에 너무 길다.** 상품 확인 → 대본 → 결과 → 구간 재생 → 캡션 → 내 영상 순서는 심사위원이 6번 눌러야 한다. review 는 «클릭 1번 → 숏폼 3개» 이고 대본은 같은 화면에 펼쳐 둔다. 대본 확인을 결과 앞에 두지 마라 — 와우 포인트(숏폼)가 30초 뒤로 밀린다.
- **«한/영 캡션» 은 현재 구현과 다르다.** API 스키마는 `hook`·`hookEn`·`caption`(한국어)·`hashtags` 다. 영어 캡션 필드는 없고 `copy()` 는 `caption + hashtags` 만 복사해 `hookEn` 도 빠진다. 화면에 «한·영» 이라 쓰려면 복사 내용에 `hookEn` 을 넣거나 문구를 «영어 후킹» 으로 낮춰라. 리서치 #7 «복사한 내용이 실제 클립과 일치» 를 우리가 스스로 어기게 된다.
- **«파일 형식/실제 용량 제한 안내»(#4)** — 맞는 말이지만 제한값을 아무도 측정 안 했다(Blob 업로드·Scribe·`maxDuration=300`). 근거 없는 숫자를 쓰느니 «2분 이하 세로 영상 권장» 한 줄이면 된다.
- **«PC·모바일 비공개 창에서 시간 재며 완주»** 는 옳지만, review 의 #8(iOS `preload=metadata` 검은 썸네일)을 리서치는 몰랐다. 모바일 확인 항목에 «iOS Safari 에서 카드 썸네일이 검지 않은가» 를 명시해야 한다.

## 3. 우리 데모에 안 맞는 리서치 주장

- **경쟁사 9곳 중 6곳(Postiz·Buffer·네이버·그립·Whatnot·CapCut)은 1.5시간 결정에 영향 0.** 「미확인」 칸이 대부분이라 근거로도 약하다. 피치 덱 «경쟁 지도» 로만 쓰고 UX 결정 근거에서 빼라.
- **바이럴 점수를 «우선순위 밖» 으로 뺀 판단 자체는 맞지만 이유가 틀렸다.** 리서치는 5/11 곳이 점수를 보여준다고 적고도 이유를 «근거 없음» 으로만 둔다. 진짜 이유는 «우리 차별점은 점수가 아니라 `why`(사고 싶어지는 순간) 다» — 이걸 카드 제목급으로 키우는 게 OpusClip 대비 메시지다. 리서치는 이 차별화를 놓쳤다.
- **«[내 영상으로 만들기] 확인» 을 60초 안에 넣기** — VC 는 영상이 없다(review #1). 링크 존재만 보이면 되고, 실제 업로드는 팀이 시연으로 대신 보여줘야 한다.
- **Whatnot 체크리스트 패턴** — 대본 UI 는 이미 구간·대사·화면 지시다. 새로 할 일이 없다.

## 4. 둘 다 빠뜨린 것

- **데모 데이터가 «어느 배포에서» 도는지.** Blob URL 을 재사용하면 스토어 삭제·만료 시 데모가 죽는다. 심사 직전 `/studio?demo=1` 을 새 창으로 한 번 더 열어 영상 재생까지 확인.
- **실제 경로 실패 시 폴백.** API 키 소진·Scribe 지연이면 시연이 멈춘다. 분석 중 화면에 «샘플 결과 보기» 링크(review §5)가 유일한 탈출구다 — P1 이 아니라 P0 와 같이 묶어라.
- **돈 이야기.** 리서치는 0줄. 랜딩 한 줄(대행사 월 100만 → 20만)이 VC 질문 1순위다.
- 미커밋 변경 다수(`page.tsx`·`site-header.tsx`·`studio-client.tsx`·`types.ts`·`demo.ts`). 배포는 push 기반이라 커밋 전엔 위 «반영됨» 이 사이트에 없다.
